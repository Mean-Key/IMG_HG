# 후속 연구와 실물 검증

## 연구 질문

- RQ1: 지정한 관찰 위치에서 기하 보정은 무보정과 아핀에 비해 어떤 형상 오차를 줄이는가? 현재 합성 기초 검증 완료.
- RQ2: 거리·눈높이·측면 위치를 잘못 측정했을 때 오차는 어떻게 전파되는가? 가정된 분포의 초기 실험 완료, 실제 측정분포 미확보.
- RQ3: 출력 면적과 해상도를 제한하면서 허용 관찰 영역을 넓힐 수 있는가? 방법·기준군 설계 단계, 구현 미실시.
- RQ4: 카메라 기반 기하 오차 감소가 사람이 느끼는 착시 품질과 연결되는가? 별도 실험 필요.

## 다음에 수행할 실험

### A. 기준군과 샘플링 개선

아핀 비교군에 관찰 영상 오차를 직접 최소화하는 적합을 추가한다. 같은 영상 각크기나 같은 출력 면적에서 비교하여 무보정의 크기 차이를 통제한다. 출력 해상도를 100·200·300·600 px/m로 바꾸고, 선·원·텍스트·자연 이미지 등 여러 유형을 고정 목록으로 평가한다. 테스트 이미지는 라이선스를 확인하고, 방법 조정에 쓴 이미지와 평가 이미지를 구분한다.

### B. 실측으로 검증

1. 실제 사용할 평면의 가로·세로와 평탄도를 기록한다. 초기 설계의 2×3 m를 실제 공간에 맞춰 조정하되 물리 단위와 출력 DPI를 명시한다.
2. 바닥에 기준점을 배치하고 인쇄 배율 또는 프로젝터-평면 매핑을 측정한다. 종이 인쇄와 프로젝터 출력은 서로 다른 설정으로 기록한다.
3. 고정 초점/줌 카메라를 보정해 내부 행렬과 렌즈 왜곡 계수를 얻는다. 촬영 중 줌·전자 손떨림 보정·자동 크롭 설정을 기록한다.
4. 거리와 카메라 광학 중심의 높이를 반복 측정한다. 발 위치나 삼각대 꼭대기 높이를 눈/광학 중심 높이와 혼동하지 않는다.
5. 위치별 여러 독립 설치·촬영을 반복한다. 반복 수는 초기 측정 변동을 보고 정하며, 아직 실행하지 않은 횟수를 결과 표에 채우지 않는다.
6. 보정용 꼭짓점과 별도의 평가 격자점으로 재투영 오차를 측정한다. 같은 네 점을 맞추고 그 점만 평가하지 않는다.
7. 탑뷰, 지정 시점, 거리·높이·측면을 바꾼 시점의 원본 사진을 보존한다. 평가 전에 비교군·지표·제외 기준을 고정한다.

### C. 오차에 강한 배치 방법 검토

참값 단일 시점 보정, 평균 시점 보정, 두 시점 최소제곱, 표본 기반 강건 목적을 비교한다. 기대 오차만 줄이면 극단 시점이 나빠질 수 있으므로 평균·95백분위·최악값을 함께 본다. 관찰 영역을 넓히기 위해 그림을 작게 만드는 편법을 막도록 최소 각크기·해상도·영역 포함 제약을 적용한다.

### D. 지각 실험 — 필요할 때 별도 수행

카메라 RMSE와 주관적인 “원처럼 보임”, 글자 가독성, 입체감은 서로 다른 결과다. 사람의 지각적 우수성을 주장할 경우 실험 순서·조건을 무작위화하고 단안/양안 관찰, 시점 표시 유무를 통제한다. 표본 수는 효과크기·변동 및 연구 목적에 맞춰 설계한다. 아직 참여자를 모집하거나 데이터를 수집하지 않았다.

## 연구 로그의 기록 규칙

매 실험에 연구 질문, 코드 해시, 입력 파일 해시, 설정, seed, 실행 시각, 성공/실패 상태, 원시 결과, 해석 및 한계를 남긴다. 실패하거나 유의하지 않은 결과를 삭제하지 않는다. 합성 데이터와 실제 측정 데이터를 다른 표로 관리한다. 그래프를 갱신할 때 이전 run을 덮어쓰지 않는다.

## Notion에 옮기는 방법

저장소 루트에서 `python research/package_notion.py`를 실행하면 `research/exports/IMG_HG_Notion_import.zip`에 Markdown과 그림을 포함한 가져오기 묶음이 생성된다. Notion의 Markdown/CSV 가져오기를 사용해 연구 페이지 아래로 옮길 수 있다. 상대 링크와 이미지 표시 여부는 가져오기 후 확인해야 한다. 이 가져오기 경로 자체를 현재 세션에서 실제로 실행해 검증한 것은 아니다.

자동 기록에 필요한 조건: 환경 설정의 NOTION_TOKEN, api.notion.com 접근, 대상 페이지를 연결에 공유한 권한. 토큰 값은 채팅에 입력하지 않는다. 현재 환경에는 인증이 없었으므로 원격 기록을 완료했다고 표시하지 않는다. 환경 설정 변경을 저장·적용한 뒤 페이지 읽기와 자식 페이지 생성 권한을 실제 요청으로 확인한다.

## 문헌 조사 재개

api.crossref.org, arxiv.org/export.arxiv.org, openaccess.thecvf.com 접근이 가능해지면 원문·서지를 대조하고, dynamic anamorphosis, anamorphic prewarping, robust projector-camera calibration, viewpoint uncertainty, spatial augmented reality 키워드로 최신 문헌을 보완한다. 특정 출판사 원문이 추가로 필요할 때 그 도메인만 추가한다. 접근 제한이 있는 동안 검색 결과의 포괄성을 주장하지 않는다.
